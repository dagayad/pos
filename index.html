Settings & Backup

Store details, currency display, data backup and restore.

Store information

Logo is saved to the cloud (auto-resized) and shown on receipts. Max file size: 2 MB.
Receipts print and download as the receipt only, sized to the paper above. In the print dialog choose your receipt printer, set Margins: None, Scale: 100% and turn off Headers and footers.

Backup & restore

Export all products, customers, sales, expenses and settings as a JSON backup. Keep a copy somewhere safe.

Data is saved to the cloud (Firebase) for this store and syncs live to every PC that logs in with this store's accounts. If the internet drops, sales are kept on this PC and uploaded when it reconnects. Still download a JSON backup regularly.

How to use

  1. Add your products and opening stock in Inventory.
  2. Use Point of Sale to add items and complete sales.
  3. Use Customers and Expenses to maintain records.
  4. Export CSV for spreadsheets or download a full JSON backup.
  5. Switch Light/Dark mode using the button in the top bar.
